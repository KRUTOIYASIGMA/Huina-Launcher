# Huina Launcher

Huina Launcher is an exciting launcher project based on the source code of Millida Launcher (kudos to them, by the way!).

While it is built entirely upon the Millida framework, I am adding some original touches—such as a "Rubicons" application (there might also be a new currency, as I don’t intend to copy everything).

I also plan to create custom accessories and much more.

The source code is not publicly available at the moment, but it will be released sometime in mid-November—or perhaps even earlier.
